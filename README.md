# Track My Mailbox — TMM_mvp Version 2

Track My Mailbox is a browser-based proof of concept for recipient awareness. It demonstrates how a recipient can see a simulated arrival after it has been recorded. No account or installation is required.

## Open the project

- **Recipient application:** Open `index.html` in Google Chrome (desktop).
- **Verification walkthrough:** Open `tests/test.html` in Google Chrome (desktop). The automatic checks run when the page opens. To run the interactive failure-and-retry walkthrough, select **Start demo** on the page.

## Browser Compatibility

Google Chrome (desktop) is the recommended and manually verified browser. Safari testing revealed an unresolved issue affecting the automatic verification page. Safari compatibility investigation is deferred to a future iteration.

This is a simulated-only prototype. It does not detect physical mail or send real notifications.
